I built Home Assistant Fleet Manager to solve a real problem in my own setup: Home Assistant had grown from one home into several environments — primary residence, parents' home, rental properties, and remote locations.

Each instance worked fine on its own. The friction was maintenance.

Checking updates, skipped items, repairs, backups, and restart needs meant logging into each Home Assistant instance manually. That is fine once. It gets old quickly across multiple properties.

Fleet Manager gives me one centralized view of fleet health across all instances, with drill-downs for updates, skipped items, repairs, backups, restarts, and recent activity.

The lesson for me: once home automation starts supporting real-world responsibilities, it becomes infrastructure. And infrastructure needs a simple maintenance surface.
