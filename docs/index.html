Home Assistant Fleet Manager

A small self-hosted app for people running Home Assistant across a primary residence, family homes, rentals, or other remote properties.

It centralizes updates, skipped items, repairs, backups, restarts, and recent activity so you do not have to log into every Home Assistant instance manually.

Why it exists

One Home Assistant instance is easy to check. Several homes make update and repair maintenance repetitive.

What it does

Shows pending updates, skipped updates, Repairs, backups, restarts, notifications, and recent activity in one place.

What the demo is

A static mock-data version of the real browser UI. It is safe to open and does not connect to Home Assistant.
